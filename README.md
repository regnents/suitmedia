# FRONTEND INTERN TEST - SUITMEDIA

### DESCRIPTION
A prototype for some company landing page. Created using HTML, CSS, and JavaScript; compiled and bundles using parcel v2([here](https://v2.parceljs.org/)).

### REQUIREMENT
<ul>
<li>npm, version 12 or higher</li>
<li>yarn, latest version</li>
</ul>

### STEPS BY STEPS FOR DEVELOPMENT SERVER
1. Open command prompt in the directory, install all the dependencies from `package.json` by running `yarn install` in the command prompt</li>
2. Run `yarn start` to start local development server</li>
3. Open the page using your browser in `localhost:1235`</li>
